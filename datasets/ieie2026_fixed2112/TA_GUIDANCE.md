# 조교 피드백과 이번 데이터·그림 작업의 적용 기준

출처: 사용자가 이 대화에서 전달한 손현호 조교의 논문 초안 피드백. 전달받은 날짜는 2026-10-16이며, 원래 이메일 발송일은 확인하지 않았다. 아래는 작업용 정리이며 학회 규정 전체를 대체하지 않는다.

## 원문에서 확인한 요구

| ID | 요구 | 이번 적용 / 원고에서 확인할 사항 |
|---|---|---|
| T01 | 인용은 문장 끝 마침표 바로 앞에 붙인다. 문장 중간에 필요하면 문장을 나눈다. | `한다[1].` 형태. `Isaac Gym[3]의` 같은 중간 인용을 전수 점검한다. |
| T02 | 비연속 인용은 `[2, 5]`, 연속 번호는 `[2]-[5]`로 묶는다. | 실제 렌더링한 PDF와 참고문헌 첫 등장 순서를 함께 검사한다. |
| T03 | 학술지·학회·arXiv 서지를 통일하고 정식 게재본이 있으면 우선한다. 저자 6명 이하는 전원, 7명 이상은 첫 저자와 et al. | 최종 원고의 참고문헌을 별도 검증한다. 이 문서에서 최신 게재 여부를 확인했다고 간주하지 않는다. |
| T04 | 장·절 제목과 Abstract·참고문헌 제목을 볼드로 한다. | 원고 렌더링에서 확인한다. 그림 속 일반 축·범례까지 모두 볼드로 하라는 요구는 아니다. |
| T05 | 이어지는 짧은 문단을 합친다. 결론은 한 문단으로 한다. | 결과는 저하율 / 관절 / 정체의 세 논리 단위, 결론은 한 문단으로 작성한다. |
| T06 | 첫 페이지 좌우 시작 위치와 장 제목 앞뒤 한 줄 간격을 통일한다. | 최종 5쪽 프로시딩과 4쪽 심사용에서 각각 확인한다. |
| T07 | 수식 위아래 한 줄 간격, 문장에 맞는 쉼표·마침표를 둔다. 모든 식을 본문에서 번호로 언급하고 기호를 정의한다. | 생존율·RMSE·횡오차·평면속도 요약식에도 적용한다. |
| T08 | 약어는 Abstract와 본문 각각 첫 등장 시 영문 풀이를 쓴다. 기법 출처 인용은 그 문장 끝에 둔다. | PD, GPU, PPO, GAE, KL, RMSE, MLP, CNN, ELU, RMA를 점검한다. 그림 안에서만 등장하는 약어도 캡션이나 본문에서 푼다. |
| T09 | 그림·표와 캡션 간격, 캡션 뒤 한 줄 간격을 통일한다. | 그림 파일 안에 논문 캡션을 중복으로 넣지 않고 TeX 캡션으로 관리한다. |
| T10 | 숫자와 단위는 줄바꿈 없는 공백으로 연결한다. 시간은 s로 통일한다. %와 °는 숫자에 붙인다. | `0.5 m/s`, `20 s`, `2 kg`, `40%`, `45°`. 그림은 축 라벨에 단위를 쓰고 눈금은 숫자로 쓴다. |
| T11 | 그림 2 상자 글씨가 작고 그림 5 어두운 셀의 숫자가 안 보인다. | 최종 삽입 크기 기준 글자 크기를 정하고, 셀 배경의 실제 밝기에 따라 흰색/검은색을 선택한다. 원본을 크게 만든 뒤 축소해 글씨가 작아지는 것을 피한다. |
| T12 | 그림 라벨과 수식의 지표 정의가 일치해야 한다. 과거 Q20 라벨과 정의가 달랐다. | 이번 주지표는 생존율·세 축 명령 RMSE·경로 횡오차 RMSE다. Q20·Q10은 다시 도입하지 않는다. |
| T13 | 고장·저하율·교사·학생 표기, 표 머리글 언어를 통일한다. | 국문은 `토크 저하`, `토크 저하율`, `교사·학생`; 영문은 `Torque degradation`, `Normal`, `Student`. 그림 라벨은 영문으로 통일한다. |
| T14 | 기존 방법을 적용했다는 말만 앞세우지 말고 새로 구성·분석한 내용을 기여로 제시한다. 관련 연구 비교를 보강한다. | 제어 구성과 동일 조건의 다방향·곡선·관절별 검증을 앞세운다. 교사·학생 공동학습의 출처는 방법 절에서 명확히 인용한다. 기존 방법을 새 알고리즘처럼 쓰지 않는다. |
| T15 | 이메일 공백, 소속 영문명, 조사·오타, 본문과 표의 범위 불일치를 고친다. | 최종 원고 별도 점검 목록에 포함한다. 새 결과 범위는 CSV로 확인한다. |

## 글꼴과 크기에 관한 구분

조교 메시지에는 **그림에 사용할 특정 글꼴 이름이나 최소 pt 값이 지정되어 있지 않다.** 따라서 아래는 기존 원고와의 일관성을 위한 프로젝트 선택이다.

- 그림의 영문 축·눈금·범례·숫자는 IEEE 공식 권고 목록의 Times New Roman으로 통일한다. 국문 본문 글꼴 설정은 별개다.
- 그림 텍스트 9 pt는 이번 제작 기준이다. 조교가 9 pt를 지정했다고 쓰지 않는다.
- 원고 수식의 Cambria Math와 그림의 일반 텍스트를 구분한다. 현재 새 그림은 영문 일반 텍스트를 사용한다.
- 폰트 파일 자체는 배포하지 않는다. PDF에는 사용한 글리프를 포함하고, 생성 로그에는 실제 선택된 폰트와 해시를 기록한다.

현재 작업이 완료한 것은 데이터 설명서, 그림 생성 코드와 시안, 결과·결론 작성 계획이다. 이 표가 기존 TeX 전체의 서식 교정을 완료했다는 확인표는 아니다. 최종 원고의 교정·쪽수·익명성 검수는 [작성 계획](PAPER_RESULTS_PLAN.md)의 별도 단계다.
