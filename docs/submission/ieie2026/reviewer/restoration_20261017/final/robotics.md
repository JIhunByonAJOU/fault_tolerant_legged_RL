# 로보틱스 관점 수정 후 AI 재검토

역할 기반 독립 AI 검토이며, 실제 외부 로보틱스 전문가의 심사·승인이 아니다. 이번 검토는 `final/manuscript.pdf`와 `manuscript.txt`를 대상으로 했다. PDF 6쪽을 렌더링해 히트맵·결과표·인쇄된 재현 자료 경로를 확인했고, PDF 메타데이터에서 7쪽임을 확인했다. 코드·원시 평가 자료·공개 상세명세의 내용은 열람하지 않았다.

**판정: 복원된 시스템·관측·공동학습 설명을 보존하면서 주요 연결 문제가 개선되었다. 기술적 구조를 삭제하거나 전면 재작성할 이유는 없으며, 5쪽 분량 충족과 재현 상세명세 완결은 남아 있다.**

## 수정 확인

- **2–3쪽 시스템 모델·표 1–4·그림 1–2:** 로봇·환경 그림, PD 제어와 포화 전 토크 배율, 100% 저하와 관절 잠금의 구분, 현재 관측표와 인코더 입출력, 보상표가 유지되었다. `48+187=235`, 교사 `1+1+12+24+6+1=45`, 학생 `50×48→8`, 정책 `235+8=243→12`는 일치한다. 교사 입력의 “추가 질량” 표기도 명확해졌다.
- **3쪽 3.2절 식 (5):** 본문이 “평균 L2 거리”라고 명시하여 제곱 없는 수식과 맞는다. 실제 동결 소스의 `vector_norm(...).mean`과 일치한다는 내용은 **작성자가 보고한 검증**이다. 본 검토자가 코드를 대조한 것은 아니다.
- **3쪽 3.3절 식 (6)–(7):** 분모 0.25의 단위를 각각 `(m/s)^2`, `(rad/s)^2`로 명시하여 차원 해석이 보완되었다.
- **4쪽 4.1절 상위 제어기:** 선행 거리 0.4 m, 횡오차 이득 0.7, 방향 오차 이득 1.5가 추가되었다. 세계 속도를 실제 yaw로 몸체 좌표로 변환하고 실제 상태에 따라 달라지는 명령으로 RMSE를 계산한다는 설명도 유지된다.
- **6쪽 4.3절·결론:** `task_metrics.csv`를 특정하고, 저장소 URL·`dev` 브랜치·`docs/submission/ieie2026/paper_assets/`·`MANUSCRIPT_EVIDENCE.md`를 인쇄 가능한 형태로 제시했다. 이전 원고에도 하이퍼링크는 있었다는 작성자 설명을 반영한다. 이번 개선은 인쇄본에서 접근 대상을 식별할 수 있게 한 것이다. 공개 서버에서 해당 파일이 실제 제공되는지는 이번 검토 범위 밖이다.
- **1쪽 초록·6쪽 4.3절·결론:** 두 고정 정책과 평가 과제에 대한 결과임을 한정하며, “종료 전 경로 횡오차”라는 지표와 주장의 연결도 명확하다. 생존율을 완주율이나 생존 시간으로 바꾸어 해석하지 않는다.

## 수치와 히트맵

6쪽 그림 9는 `Fall rate (%)` 0–100 색 막대이며, 낙상률이 높을수록 청색이 진하다. 캡션의 `100%−생존율`, 셀 값, 4.4절의 취약 관절 설명은 일치한다. 100% 저하의 FR hip/RR thigh 2.78%, FL thigh 21.30%, FR thigh 28.24%와 표의 한 자리 표시는 일관된다.

216시행/셀 기준으로 표시값을 정수 복원하면 100% 열의 낙상 합계는 279회이고, 전체 생존율은 `1−279/2592=89.2361%→89.24%`이다. 표 6의 과제별 생존율은 Normal 1,350회, Student 2,313회의 비낙상 수와 양립하며, 차이는 `37.1528%p→37.15%p`이다. 경로 RMSE의 2:1:1:2 가중 평균도 `0.225 m`, 약 `0.07967 m→0.080 m`로 일치한다.

x속도 RMSE 감소 47.0%, 경로 RMSE 감소 64.6%는 **작성자가 반올림 전 수치로 확인했다고 보고하여 유지한 값**이다. 이번 검토는 원수치를 직접 확인하지 않았다. 표시값만으로 다시 계산해 수치를 바꾸라고 요구하지 않는다. 재현 명세에 반올림 전 수치로 감소율을 계산한다는 규칙을 남기면 충분하다.

## 남은 수정

1. **분량 필수:** 목표 5쪽에 현재 7쪽으로, 분량 요건은 미충족이다. 사진·표 1–4·관측 차원·시스템 모델·공동학습 구조를 보존하고, 반복 설명·그림 패널 배치·여백을 중심으로 편집해야 한다.
2. **재현 명세 완결:** 관측 정규화/클리핑과 지형 높이 기준, 근사 투영 방법, 상위 제어기 식과 속도 노름 적용 순서, 보상 세부항 정의를 상세명세에 남겨야 한다. 작성자로부터 보완 중이라고 전달받았으며, 이번 검토에서 완료를 확인한 것은 아니다. 이 내용을 전부 본문에 늘릴 필요는 없다.
3. **접근성 마감 확인 권고:** 인쇄 경로가 여러 줄에 걸쳐 나뉘지만 URL·브랜치·파일명은 식별 가능하다. 최종 제출 전 명시한 공개 파일의 접근 가능 여부와 최종 원고 버전 대응을 확인하면 좋다.

단일 학습 시드, 다른 학습 이력·표현을 갖는 두 구성 비교, 정책별 종료 시점·방문 지형·실제 명령의 차이라는 기존 해석 한계는 유지되어 있다. 현재 원고는 해당 실험 범위의 시뮬레이션 결과를 설명하며, 실물 재현이나 학습 방법만의 인과적 우월성을 입증한 것으로 확대하지 않는다.
