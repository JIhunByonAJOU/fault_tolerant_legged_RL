# 로보틱스 관점 독립 AI 검토

이 문서는 로보틱스 전문가 역할을 부여한 AI의 독립 검토이며, 실제 외부 전문가의 심사·승인이나 실험 재현 확인이 아니다. 검토 자료는 이 디렉터리의 `manuscript.pdf`와 `manuscript.txt`뿐이다. 이전 리뷰·계획·원시 평가 자료·구현 소스·외부 문헌은 열람하지 않았다. PDF의 2·3·6쪽은 렌더링하여 사진·표·모식도·히트맵을 직접 확인했다. 아래의 쪽수는 PDF 인쇄 쪽수이다.

## 종합 판정

**시스템 모델, 공동학습 구조, 로봇·환경 그림, 현재 관측표, 차원표, 보상표는 보존할 가치가 있으며, 전면 재작성이나 삭제를 요구할 기술적 모순은 발견하지 못했다.** 포화 전 토크 배율과 관절 잠금의 구분, 학생이 직접 고장 정보를 받지 않는다는 설명, 48/187/235/45/8/243/12차원은 내부적으로 일치한다. 새 평가도 생존율·종료 전 RMSE·출구 도달을 구분하여 설명한다.

다만 **프로시딩 목표 5쪽에 대해 현재 7쪽이므로 분량 요건은 미충족**이다. 공개 보조자료의 접근 경로와 재현에 필요한 관측·상위 제어기 정의도 보완해야 한다. 결과의 인과적 해석은 현재 명시한 ‘학습·표현·학습 이력이 다른 두 고정 구성의 비교’ 범위로 유지해야 한다.

## 필수 수정

### F1. 공개 재현 명세·보조표의 실제 식별자를 제시할 것

- 위치: 6쪽 4.3절의 “각 과제의 세 축 명령 RMSE 평균도 모두 감소하였다(공개 보조표)”, 결론 말미 “설정·추출 규칙·과제별 수치는 공개 재현 명세에 제공한다.”
- 문제: 원고에는 해당 명세·표의 URL, DOI, 참고문헌 번호 또는 파일 식별자가 없다. 이 두 문구는 독자가 현재 원고만으로 확인할 수 없는 근거를 가리킨다. 특히 과제별 세 축 명령 오차의 감소 주장은 표 6에 제시되지 않아 보조표 접근이 필요하다.
- 최소 수정: 동일한 공개 명세를 가리키는 짧은 URL/참고문헌을 1개 추가하고, 과제별 명령 RMSE 표의 위치를 지정한다. 본문 수치나 복원된 표를 삭제할 이유는 없다.

### F2. 원고 또는 접근 가능한 재현 명세에서 관측·상위 제어기의 정의를 완결할 것

- 위치: 2쪽 표 2·3.1절, 4쪽 4.1절의 “접선 속도와 횡오차 피드백을 결합해 0.5 m/s의 세계 속도 명령”.
- 문제: 표 2는 물리량의 구성·단위를 잘 보여 주지만, 187차원 지형 높이가 어느 기준의 높이인지, 관측 정규화·클리핑을 적용하는지 설명하지 않는다. 상위 제어기는 피드백 이득, 속도 0.5 m/s를 결합 전 접선 성분에 적용하는지 결합 후 전체 벡터 노름에 적용하는지, yaw 오차에서 회전 명령을 만드는 법이 불명확하다. 이 차이는 세 축 명령 RMSE와 경로 오차를 모두 바꾼다.
- 최소 수정: 표 2는 유지하고 관측 물리량/정규화의 구분과 높이 기준을 짧게 명시한다. 상위 제어기 식·이득·속도 제한 및 사인파 근사 투영 방법은 F1의 명세에 연결해도 충분하다. “실제 yaw로 몸체 좌표로 변환”한다는 기존 설명은 유지한다.
- 범위: 구현과 다르다고 판정한 것이 아니라 재현에 필요한 정의가 원고에서 닫히지 않았다는 지적이다.

### F3. 필수 복원 요소를 보존하면서 5쪽 제한을 충족할 것

- 위치: PDF 전체 7쪽, 7쪽에는 참고문헌이 이어진다.
- 최소 수정 방향: 그림 1의 로봇·환경 사진, 표 2의 관측 항목과 차원, 표 3의 인코더/정책 입출력, 시스템 모델과 공동학습 설명, 보상표를 보존한다. III–IV절에 반복되는 차원·학습 단계 설명, 결과의 반복 서술, 그림 주변 여백과 표의 행간을 우선 조정한다. 학회 서식과 가독성을 지키면서 관련 성능 곡선을 패널로 묶는 방안도 가능하다. 필수 사진/관측표/차원 삭제나 두 절의 전면 재작성을 분량 해결책으로 권하지 않는다.

상위 제어기의 횡오차 피드백은 정책별 상태에 따라 서로 다른 명령을 만든다. 따라서 명령 RMSE 감소는 동일한 고정 시계열 명령의 추종 성능 비교와 같지 않다. 원고가 “실제 명령”을 기준으로 한다고 명시한 점은 적절하다. 경로 RMSE와 출구 도달까지 함께 제시한 현재 연결을 유지하는 것이 필요하다.

## 그림 9 낙상률과 숫자 검산

**히트맵은 생존율의 여수인 낙상률로 올바르게 표시되어 있다.** PDF에서 색 막대는 `Fall rate (%)`, 범위는 0–100이며, 값이 클수록 청색이 진하다. 100% 저하의 FR thigh 28.2가 FR hip 2.8보다 진하다. 캡션은 `낙상률=100%-생존율`, 4.4절은 높은 낙상률을 취약 조건으로 설명하여 색·값·캡션·본문의 의미가 일치한다. 생존율로 되돌리거나 색을 뒤집을 필요는 없다. 캡션에 “진할수록 낙상이 많음”을 짧게 덧붙이는 것은 선택 사항이다.

| RMSE 감소율 | 표시값만으로 계산하면 x속도 46.90%, y속도 57.25%, yaw-rate 67.61%, 경로 64.44%이다. 본문의 47.0/57.3/67.6/64.6% 중 x와 경로 값은 표시값만으로 그대로 재현되지 않는다. 다만 표시 전 원수치의 반올림 오차 범위에서 가능한 값이므로 오류로 단정하지 않는다. 감소율은 반올림 전 수치로 계산했는지 확인하고 그 규칙을 명세에 명시할 것을 권고한다. |

시간 상한도 본문의 정의와 대체로 맞는다. 직선 길이 41.5 m이면 `41.5/0.1+30=445 s`이다. 사인파를 원고 식 그대로 연속 적분하면 A=1.5 m에서 약 479.8798 s로 표 5의 479.88 s와 일치한다. A=2 m에서는 약 504.6088 s로, 표의 504.62 s와 약 0.011 s 차이가 있다. 경로 이산 근사나 제어 시점 반올림으로 설명 가능한 작은 차이이다. 경로 길이 L의 수치 계산·반올림 규칙을 재현 명세에 남기고, 실제 적용한 상한을 기준으로 표기하면 된다.

## 권고하는 최소 수정의 범위

1. 공개 명세와 과제별 명령 RMSE 보조표의 접근 경로를 추가한다.
2. 해당 명세에서 관측 높이 기준·정규화, 상위 제어기 식·이득, 경로 투영, 보상 세부 정의, 수치 반올림 규칙을 닫는다.
3. 현재 시스템 모델·사진·관측표·차원표·공동학습 구조·보상표와 결과의 해석 한계를 보존하면서 5쪽으로 편집한다.
4. 식 (5)의 노름 정의와 실제 감소율 계산은 저자가 구현/원수치에 대조한다. 본 검토는 해당 자료를 열람하지 않았으므로 확인 완료로 표시하지 않는다.

위 보완은 복구한 설명을 유지하면서 재현성과 해석의 정확도를 높이는 국소 수정이다. 논문 전체의 연구 구성을 다시 쓰거나 필수 표·사진을 제거할 근거는 발견하지 못했다.
