# 서론·학습 그림·정량 평가 편집

최신 [프로시딩 PDF](private/latex/preview/proceedings.pdf)와 [익명 PDF](private/latex/preview/main.pdf)는 각각 **6쪽·6쪽**이다. 목표 5쪽·4쪽은 아직 미충족이다. 이전 복구본의 7쪽·6쪽 상태와 구분한다. 이전 원고에 대한 AI 리뷰를 이번 편집본에 대한 새 심사로 표시하지 않는다.

사용자가 제시한 두 문단 서론을 두 원고에 적용했다. 문장 끝 인용만 추가했고, 기존 시스템·관측표·입출력 차원·보상표·사진·구조도는 보존했다. 본문에서 RMA 계열 등의 표현을 삭제하되 문헌 인용은 유지했다.

그림 3은 이전 `paper_learning_v10.pdf`의 상단 보상·하단 가중치 구성을 복구한 것이다. Teacher–Joint–Student only 구간을 표시하고 공동학습 구간을 분홍색으로 칠했다. 곡선은 보존한 동일 학습 CSV이며 가중치는 기록된 alpha와 대조했다. 전체 Times New Roman 9 pt, 80×63 mm다.

그림 4는 생존율 한 패널 아래에 vx/vy 및 yaw-rate/횡오차의 2×2 패널을 둔 한 단 그림이다. 80×107 mm, 전 글자 9 pt, 각 축·단위·범례와 시드 음영을 유지했다. 독립 곡선 파일도 계속 제공한다. 내부 제목은 없으며 각 패널의 지표는 y축과 원고 캡션에서 구분한다.

그림 5(이전 그림 9)는 Student 낙상률이다. 값은 그대로이며 색 범위를 0–100%에서 0–30%로 조정했다. 실제 최대 28.24%에 대해 기존 범위가 대부분을 밝게 표시하던 문제를 해결했다. 선형 색 막대·단위·범위를 명시하고 밝기에 따라 숫자를 검정/흰색으로 표시한다.

3.4절은 정책의 학습 설정, 표 5는 두 정책의 평가 조건이다. 학습과 평가를 섞지 않았다. 표 5는 지형·과제·속도/경로·고장·반복의 다섯 항목으로 줄였고 본문에서는 동일 조건·낙상·완주·시간 상한·지표 계산에 필요한 정보만 남겼다. 상세 슬롯 추출과 시드 ID, CSV 파일명, GitHub 주소와 재현 안내는 논문 본문에서 제거했다.

표 6은 과제별 생존율과 완주율로 변경했다. 기존 생존율+횡오차 표는 여러 추종 지표 중 횡오차만 택해 그 목적이 불분명했다. 새 표는 낙상하지 않았다는 사실과 실제 경로 종료점까지 도달했다는 사실을 구분한다. 몸체 x축 속도는 횡이동·대각에서 경로 진행속도와 다르므로 혼합 과제의 진행 여부를 그대로 대표할 수 없다. 완주율은 기존 종료 기록의 보조 집계이며 새로운 주지표로 교체한 것은 아니다. 시간 상한 비낙상에는 느리게 진행한 경우도 있어 이를 전부 정체로 부르지 않았다. 정체 사례는 짧게 유지하고 결론의 주제로 삼지 않았다.

생존율·다축 명령 추종·경로 추종의 전체 성능 → 과제별 실제 주행 → 관절별 절대 낙상률 → 결론의 순서로 작성했다. 초록은 생존율과 경로 횡오차 한 개의 대표 결과만 유지한다. 결론 뒤 저장소·설정·추출 규칙 안내는 삭제했다.

LuaLaTeX 두 원고 빌드, 수식·그림·표의 본문 참조, 문장 끝 붙임 인용·순서, 글꼴 임베딩·잘림·익명성, 성능 곡선의 원집계 일치, 낙상률 60셀·완주율 정수 검산을 실행했다. [현재 검사 결과](paper_assets/manuscript_validation.json)를 따른다. 원자료와 새 학습·평가 없이 기존 26,352시행을 사용했다.
