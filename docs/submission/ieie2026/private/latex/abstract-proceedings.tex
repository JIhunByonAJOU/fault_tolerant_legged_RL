Quadruped robots should maintain balance and execute motion commands and reference paths in both normal operation and conditions with joint torque degradation. This paper presents a reinforcement-learning locomotion control architecture based on an existing teacher–student joint-training framework, using a single policy for normal operation and single-joint torque degradation. The student extracts control-relevant features from observation history without explicit inputs specifying the degraded joint or torque degradation level. In Unitree A1 simulations, the student is compared with a policy trained only under normal conditions using matched initial states, physical parameters, terrain, and fault conditions. Forward, diagonal, lateral, and sinusoidal-path tasks are evaluated using survival rate, motion-command tracking errors, and cross-track root mean square error (RMSE).
