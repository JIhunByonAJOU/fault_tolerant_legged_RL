\noindent\textbf{요약}\quad 4족 보행 로봇은 정상 상태뿐 아니라 관절의 토크가 저하된 상황에서도 균형을 유지하며 이동 명령과 목표 경로를 수행할 수 있어야 한다. 본 논문은 정상 상태와 단일 관절의 토크 저하 상황에 동일한 정책으로 대응하는 교사·학생 공동학습 기반 강화학습 보행 제어 구성을 제시한다. 학생은 관측 이력에서 제어에 필요한 특징을 추출하며, 고장 관절과 토크 저하 수준을 직접 입력받지 않는다. \noindent\textbf{Abstract}\quad Quadruped robots should maintain balance and execute motion commands and reference paths in both normal operation and conditions with joint torque degradation. This paper presents a reinforcement-learning locomotion control architecture based on an existing teacher–student joint-training framework, using a single policy for normal operation and single-joint torque degradation. The student extracts control-relevant features from observation history without explicit inputs specifying the degraded joint or torque degradation level. In Unitree A1 simulations, the student is compared with a policy trained only under normal conditions using matched initial states, physical parameters, terrain, and fault conditions. Forward, diagonal, lateral, and sinusoidal-path tasks are evaluated using survival rate, motion-command tracking errors, and cross-track root mean square error (RMSE).\par
\smallskip\noindent\textbf{Keywords:} Quadrupedal locomotion, Actuator degradation, Teacher–student learning, Joint learning
