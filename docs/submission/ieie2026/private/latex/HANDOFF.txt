Agreed metrics for the NEXT evaluation:
1. 생존율: normalized mean post-fault survival time, 0 to 1.
   This is different from the endpoint survival percentage in the current manuscript.
2. 이동 명령 추종: vx/vy RMSE in m/s and omega_z (yaw rate) RMSE in rad/s.
3. 경로 추종: cross-track error RMSE in m, measured perpendicular to the reference path.
ADE, Q and forward displacement are not the intended primary metrics for the next evaluation.
Report error calculation intervals and handle terminated/no-sample trials explicitly.

Use paired physical conditions, fault schedules and evaluation seeds between policies.

Notation:
- velocity command: v_x^{cmd}, v_y^{cmd}, omega_z^{cmd}
- reference path: p^{ref}(s)
- actual trajectory: p(t)
- omega_z is body-frame z-axis angular velocity, not the yaw angle.
The policy outputs 12 action values that set desired joint angles q_des=q0+0.25*a.
Body velocity time series are measured rollout outcomes, not predicted future policy outputs.
