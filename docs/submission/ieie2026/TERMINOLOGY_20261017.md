# 원고 용어와 결과 서술 정리

## 통일한 용어

| 대상 | 원고 표기 | 구분 |
| --- | --- | --- |
| 고장 현상 | 관절 토크 저하 | 토크 출력 배율이 감소하는 모델 |
| 감소 정도 | 토크 저하율 $d$ | $0\leq d\leq1$; 본문과 그림에서는 백분율도 사용 |
| 적용 배율 | 고장 배율 $\eta_j$ | 고장 관절에서 $1-d$, 나머지 관절에서 1 |
| 적용 위치 | 고장 관절 $j_f$ | 관절 잠금과 구분 |
| 대조 정책 | 정상학습 정책(Normal) | 특권 물리 정보의 교사 인코더 사용 |
| 제안 정책 | 고장대응 정책(Student) | 관측 이력 기반 학생 인코더 사용 |
| 평가 항목 | 생존율, 이동 명령 추종 오차, 경로 횡오차 | 생존율은 평가 종료까지 비낙상한 시행의 비율 |
| 주행 종료점 도달 | 완주율 | 정체 사례를 생존율만으로 해석하지 않도록 함께 제시 |
| 본체 | 몸체 | base 링크라는 표현 제거 |

‘관절의 토크가 저하되면’처럼 문장 안에서 풀어 쓴 동사 표현은 유지한다. 같은 현상의 명칭으로 손실, 열화, 구동기 저하 등을 혼용하지 않는다. 국문 제목과 영문 제목도 각각 관절 토크 저하와 joint torque degradation으로 맞췄다.

가운뎃점은 국문 제목, 요약, 본문, 캡션에서 모두 제거했다. 열거에는 쉼표를 쓰고, 서술상 자연스러운 연결에는 ‘와/과’를 사용했다. 수식의 곱셈 기호와 N·m 같은 단위의 곱셈 표기는 유지한다. 표 5의 범위는 `20\textasciitilde{}100\%`로 작성하여 실제 물결표가 출력되도록 했다. 무차원 관측 단위는 1로 표기한다.

## 문장과 그림의 변경

- 3.1: 표 3의 교사 인코더 입력 45차원, 특징 8차원, 학생 이력 50×48, Actor 입력 243차원과 출력 12차원을 설명하는 흐름으로 통합했다. 지형 높이의 이력 제외도 이력 정의에 넣었다.
- 그림 2: 기존 벡터 구조의 상자, 화살표, 내부 차원, 글꼴을 보존하고 주변의 Training, Critic, Inference 설명 세 줄만 제거했다. 재생성은 `clean_architecture_figure.py`를 사용한다(PyMuPDF 1.24.2 이상).
- 4.1: 정책 비교, 지형과 주행 과제, 지표 정의의 순서로 문단을 구성했다. 수식과 기호 설명은 각 지표 정의에 연결했다. 시간 상한의 수치와 별도 운영 절차 문단을 삭제했다. 실제 수집 프로토콜과 원자료는 변경하지 않았다.
- 캡션: 그림과 표는 제목 및 필요한 단위만 남겼다. 패널 순서, 평가 시드 음영, 히트맵 색의 로그 스케일 설명은 본문으로 옮겼다.
- 4.2: 큰 관절 토크 저하에서 보행과 추종 성능이 함께 유지된다는 결과를 먼저 제시했다. 대표 생존율과 경로 횡오차만 숫자로 제시하고 모든 축의 RMSE를 다시 나열하지 않는다.
- 표 6: 과제 간 순위를 매기기 위한 표가 아니다. 생존율 향상이 실제 주행의 완주로 이어지는지, 그 양상이 네 과제에서 공통으로 나타나는지 보여준다. 생존했지만 완주하지 못한 시행 전체를 정체라고 부르지 않는다.
- 4.3: 정체가 관찰된 사례를 짧게 제시하며, ‘보조 사례’ 또는 ‘보조 해석’이라는 표현을 삭제했다. 관절별 절대 성능은 Student 낙상률 히트맵으로 제시한다.

## 검증과 남은 분량

두 원고는 LuaLaTeX의 `private/latex/build/`에서 빌드하고, `validate_manuscript.py --publish-previews`를 통과한 PDF만 미리보기에 복사한다. 번호, 링크 대상, 인용 위치와 순서, 원자료 대비 집계, 글꼴 임베딩, 잘림, 익명성을 검사한다. 최신 검사 결과는 `paper_assets/manuscript_validation.json`을 따른다.

현재 프로시딩과 익명 심사용은 각각 6쪽이다. 5쪽과 4쪽 제한은 아직 충족하지 못했다. 이번 수정에서 복구한 시스템 모델, 관측표, 차원표, 학습 설정, 로봇 사진을 삭제해 분량을 맞추지는 않았다. 학습이나 시뮬레이션 평가를 재실행하지 않았다.
