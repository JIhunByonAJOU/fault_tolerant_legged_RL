# 최종 발표 자료

최종 발표는 43슬라이드의 융합캡스톤디자인2 초안 발표이다.

- [편집용 최종 PPTX](<융캡2 초안 발표 최종본/융합캡스톤디자인2_1조_초안발표_최종본.pptx>)
- [최종 PDF](<융캡2 초안 발표 최종본/융합캡스톤디자인2_1조_초안발표_최종본.pdf>)
- [수식 설명](presentation_equations.md), [발표 해설](presentation_notes.md)

발표 영상 TF43000, JT43000, JT43500, JT71500은 최종본과 같은 폴더에 보관한다. 이전 v1–v12 PPTX/PDF와 중간 빌드·검수 파일은 제거했다. 보조 자료는 최종 해설에 필요한 두 JSON만 남겼다.

이 발표는 TF43000/JT71500 단계의 발표 최종본이며, [현재 논문](../submission/ieie2026/private/latex/README.md)의 JT77500 평가 원고와 작성 시점이 다르다. 두 자료의 실험 대상을 구분하여 읽는다.
