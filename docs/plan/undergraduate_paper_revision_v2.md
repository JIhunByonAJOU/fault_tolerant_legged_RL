# 5쪽 학부 논문 준비 계획 v2

작성: 2026-09-28. 현재 산출물은 평가기 수정 및 기존 정책 진단이다. 학습/체크포인트는 변경하지 않는다.

## 1. 논문의 범위와 주장

**연구 질문:** 단일 관절의 모터 출력이 주행 중 저하되는 상황에서, 기존 teacher–student 공동학습을 적용한 학생 정책은 속도 명령 추종과 보행 유지를 어느 범위까지 달성하는가?

- 공동학습 자체의 발명이나 Saving the Limping 대비 알고리즘 신규성을 주장하지 않는다.
- Saving the Limping의 공동학습 아이디어, WIM/legged_gym 기반 관측·보상, ADAPT와 관련된 출력 저하 모델의 출처를 구분한다.
- 단일 관절 출력 저하를 Isaac Gym A1 환경에 구현하고, 고장 강도·관절에 따른 성능과 한계를 분석하는 응용/실험 연구로 작성한다.
- 학생 vs 특권정보 티처는 구현 진단/성능 격차 비교다. 티처를 배포 가능한 경쟁 방법으로 해석하지 않는다.
- 공동학습 vs 분리학습 우월성을 핵심 주장으로 삼으려면 동일 환경·예산으로 별도 baseline 학습이 필요하며, 그 질문 자체는 선행연구와 겹친다. 이번 5쪽 논문의 필수 신규성으로 삼지 않는다.

## 2. 지금 수정한 평가

실행 파일:
- `legged_gym/scripts/evaluate_onset_v2.py`
- `legged_gym/scripts/run_onset_v2_diagnostic.py`
- `legged_gym/evaluation/onset_protocol_v2.py`

기존 v1 evaluator/JSONL은 보존한다. 논문 준비의 신규 평가 경로는 v2다. 기존 평가의 모든 수치가 틀렸다는 뜻은 아니다. 특히 명령 갱신과 학생 관측 사이의 불일치 가능성을 수정했으며, 실제 차이는 재평가로 판단한다.

### 고정 조건

| 항목 | v2 진단 |

런타임에서 실제 명령, 현재 관측의 명령, 학생 history의 명령을 확인한다. 초기/리셋 history의 zero padding은 허용한다. 고장 주입 시 특권정보 motor-strength/flag만 갱신하여 history를 중복 추가하지 않는다.

### 지표

`T=20 s`, `K=T/Δt=1000`, 고장 시각 `t_f`. 오류는 몸체 좌표계에서 정의한다.

\[
e_x(t)=v_x(t)-v_x^{cmd},\quad e_y(t)=v_y(t)-v_y^{cmd},\quad e_\omega(t)=\omega_z(t)-\omega_z^{cmd}.
\]

**생존율:** 고장 후 20초가 끝날 때까지 환경의 실패 종료 조건을 만나지 않은 에피소드 비율. 현재 환경에서는 종료 대상 몸체의 접촉력 norm이 1 N을 넘으면 종료한다. 이 정의가 모든 형태의 비정상 자세를 검출한다는 뜻은 아니다. 고장 전 종료도 실패로 포함한다. 마지막 transition에서 종료한 경우도 실패다.

**추종 충족 시간 비율:**

\[
Q=\frac1K\sum_{k=0}^{K-1}
\mathbf1[\text{alive}(t_f+k\Delta t)]
\mathbf1[|e_x|\le0.1\ \mathrm{m/s},\ |e_y|\le0.1\ \mathrm{m/s},\ |e_\omega|\le0.2\ \mathrm{rad/s}].
\]

- `Q=0.8`이면 고장 후 20초 중 16초 동안 살아 있으면서 세 가지 추종 기준을 동시에 충족했다.
- 넘어지고 난 뒤 시간도 분모에 남는다. 조기 종료로 어려운 구간이 사라져 점수가 좋아지는 것을 방지한다.
- 이 threshold 조합은 **프로젝트의 평가 설계**이며, 선행논문에서 검증된 동일 표준이라고 주장하지 않는다.
- 결과를 본 뒤 기준을 완화하지 않는다. 엄격 `(.05,.05,.1)` / 기본 `(.1,.1,.2)` / 완화 `(.2,.2,.4)` 민감도를 함께 저장한다.
- 마지막 5초의 추종 충족 시간 비율도 보조 지표로 저장한다.

**속도/yaw rate RMSE:**

\[
\mathrm{RMSE}_{v_x}=\sqrt{\frac{1}{N_i}\sum_{k\in\mathcal V_i}e_x(k)^2},
\quad
\mathrm{RMSE}_{v_y}=\sqrt{\frac{1}{N_i}\sum_{k\in\mathcal V_i}e_y(k)^2},
\quad
\mathrm{RMSE}_{\omega_z}=\sqrt{\frac{1}{N_i}\sum_{k\in\mathcal V_i}e_\omega(k)^2}.
\]

`𝒱_i`는 고장 이후, 최초 종료 이전의 유효 샘플 집합이다. 표에는 에피소드별 RMSE의 평균을 사용한다. 유효 샘플이 없으면 0이 아니라 null이다. 실패 이후 오차는 관측할 수 없으므로 RMSE만으로 성공을 평가하지 않고 생존율 및 Q와 함께 읽는다. 평균 실제 전진속도도 단위 m/s로 저장한다.

**기존 1초 회복률:** `|e_x|≤.1`, `|e_ω|≤.2`를 연속 1초 만족한 적이 있는 에피소드 비율. 고장에 의한 성능 하락 여부를 확인하지 않으므로 ‘한 번의 안정 추종 구간 획득률’에 더 가깝다. 지속 추종 회복의 주지표로 쓰지 않는다. 과거 자료와의 연결을 위해 보조 항목으로 유지한다.

v2는 onset 분포·초기화·종료 경계도 정리했으므로, v1과 v2의 수치 차이를 모두 명령 버그 수정의 인과효과라고 해석하지 않는다. 그 분리는 별도의 고정 조건 ablation이 필요하다.

## 3. 재학습 판단과 최소 수정 범위

1. v2로 현 체크포인트의 성능을 확인한다. 기준을 성능에 맞춰 바꾸지 않는다.
2. d별 성능을 보아 주된 한계가 중간 강도인지, d=1 완전 상실인지 구분한다.
3. 고장 미학습 정상 정책을 같은 평가 환경에 넣는 내부 대조군을 추가한다. 정상 정책은 d=0인 현재 fault-trained 정책과 다르다.
4. 정상 모델의 checkpoint와 관측 계약을 확인하고, 특권정보 사용 여부를 비교표에 명시한다. 현재 정상 Teacher243 체크포인트만 사용한다면 일반 학생 정책과 동등한 baseline이라고 부르지 않는다.
5. 실제 학습 수정은 확인된 결함에 한정한다. onset은 이미 2–10초 무작위이므로 다시 바꿀 필요 없다. 현재 명령 분포도 직진/회전을 포함하므로 논문 평가를 위해 즉시 바꿀 필요는 없다.
6. 재학습 시 보상·모델·학습분포를 한꺼번에 바꾸지 않는다. 비교할 구버전 유지, 동일 seed/예산 baseline과 변경점 한 개를 우선한다.
7. 최종 표는 설정/체크포인트를 고정한 뒤 별도 평가 seed와 지형으로 생성한다. 이번 seed 101–103 결과는 진단 자료다. 학습 seed 1개인 사실도 공개한다.

성능 하락이 확인되더라도 결과를 숨기거나 조건을 사후에 빼지 않는다. 중간 출력 저하에서는 유효하지만 완전 상실에서는 제한적이라는 결론도 가능하다. 논문 주장을 실제 결과 범위에 맞춘다.

## 4. 속도 명령과 글로벌 경로

현재 학습 명령은 약 10초마다 갱신되는 `v_x`, `v_y`, heading target이다. heading 오차를 yaw rate로 변환하여 정책에 전달한다. 학습이 정해진 직진→원호→후진 궤적을 따라가는 것은 아니다.

현재 정책은 global `(x,y)` 기준 경로의 횡오차를 입력받는 path follower가 아니다. 명령을 적분한 시각화 선을 독립적인 목표 경로 또는 path RMSE 기준으로 쓰지 않는다.

추후 글로벌 경로를 사용할 구조:

```
세계 좌표계 목표 경로/시간 궤적 + 현재 위치·자세
                 ↓ 위치·방향 오차 피드백
상위 경로 추종기: 몸체 좌표계 vx, vy, yaw rate 명령
                 ↓
하위 학습 보행 정책 → 12개 목표 관절각 → PD → 모터
```

예를 들어 시간 궤적의 전역 속도 feedforward에 위치 오차 feedback을 더한 뒤 몸체 좌표계로 회전시킬 수 있다.

\[
\mathbf v_{cmd}^{b}=R(\psi)^\top\left(\dot{\mathbf p}_{ref}^{w}+K_p(\mathbf p_{ref}^{w}-\mathbf p^{w})\right),
\quad
\omega_{cmd}=\dot\psi_{ref}+k_\psi\operatorname{wrap}(\psi_{ref}-\psi).
\]

이는 설명용 상위 제어기 예시이고 현재 구현된 알고리즘이 아니다. 명령 한계·선행점·곡률/속도 제한 등을 추가해야 한다. 경로를 미분하여 명령을 한 번 계산하는 것만으로는 고장 후 위치 오차를 되돌릴 수 없다.

이번 논문: 0.5 m/s 직진 명령을 기본, 여력이 있으면 다른 직진 속도 및 일정 yaw rate 좌/우 회전을 보조 시험으로 추가. 원호처럼 보이는 주행과 기준 원호 경로 추종의 표현을 구분한다.

## 5. 지형 및 타 논문 비교

현재 학습은 trimesh 기반 경사·거친 경사·계단·장애물 혼합 지형과 curriculum을 사용한다. 학부 논문용 시작 범위로 충분하며 지형 종류 확대를 우선하지 않는다. 혼합지형 성능만으로 모든 지형 일반화를 주장하지 않는다. 평지 대조 시험은 추후 원인 분리에 유용하다.

비교 표를 분리한다.

- **같은 환경의 실험:** 정상 정책/현재 학생/특권정보 티처. 동일 명령, 고장, 지형, horizon으로 평가.
- **문헌 참고:** 원논문 보고값과 목표 속도, 로봇, 고장 종류, 지표 정의, horizon을 함께 기록. 재실험 결과처럼 나란히 순위를 매기거나 우월성 퍼센트를 계산하지 않는다.

Saving the Limping의 joint locking과 이 프로젝트의 torque attenuation은 다른 고장이다. 그 논문의 정규화 생존 시간과 여기의 20초 완주 비율도 같은 지표가 아니다.

ADAPT는 공식 공개 코드가 있다: https://github.com/WentDong/Adapt (2026-09-28 확인). 코드 존재와 본 환경에서의 검증된 재현은 별개다. 이번 학부 논문에서 재현이 완료되지 않았다면 문헌 참고로 제한한다.

상하위 분리의 선행 사례: PRELUDE 공식 코드/논문 소개 https://github.com/UT-Austin-RPL/PRELUDE . 상위 navigation command와 하위 gait generation을 분리한다. 모든 4족 시스템이 동일 구조를 쓰는 것은 아니다.

## 7. 후속 연구로 남길 범위

관절 locking, 복수 관절 동시 고장, 점진적 저하/고장 변경, 상위 경로 추종, 지형 OOD, 공동학습·분리학습의 다중 학습 seed 통제 비교. 이들을 한꺼번에 추가하는 것 자체가 신규성은 아니므로, 후속 연구에서는 공통 fault representation 또는 적응 메커니즘에 대한 별도 가설을 세운다.
